# 📖 第一章：關聯式資料庫管理系統 (RDBMS) 與 SQLite 概論

本章將介紹關聯式資料庫管理系統（RDBMS）的基本結構與運作原理，並深入探討一個特殊且廣泛使用的輕量級 RDBMS 引擎——SQLite 的特性與應用。

---

## 一、關聯式資料庫管理系統 (RDBMS)

關聯式資料庫管理系統（Relational Database Management System，RDBMS）是一種採用關聯式資料模型來管理資料的軟體系統。它作為資料庫管理系統（DBMS）的一種，是使用者與資料庫互動的核心介面。

### 1. 核心功能與互動
- **資料庫管理系統 (DBMS)：** 負責與資料庫互動，允許使用者控制資料庫存取、寫入、執行查詢以及進行其他管理任務。
- **RDBMS 定義：** 採用**關聯式資料模型**的 DBMS。
- **互動方式：** 使用者主要透過撰寫 **SQL（結構化查詢語言）** 程式碼來與 RDBMS 進行資料互動。
- **常見 RDBMS 範例**：_ Microsoft SQL Server、Oracle、Postgres SQL、MySQL、SQLite 等。
### 2. 關聯式資料模型的結構
在關聯式模型中，資料的組織方式是高度結構化的：

| **結構元件**            | **說明**                            |
| ------------------- | --------------------------------- |
| **表格 (Tables)**     | 資料庫的基礎結構，所有資料皆以表格形式儲存。            |
| **關係 (Relations)**  | 資料庫通常包含多個相互連接的資料表，這些連接定義了資料之間的關係。 |
| **欄位 (Attributes)** | 定義資料表的結構，代表資料的屬性。                 |
| **紀錄 (Tuples)**     | 資料表中的每一行，由一組共享相同屬性值的序列值組成。        |

## 二、SQLite：輕量級與無伺服器資料庫

SQLite 是 RDBMS 中一個獨特且極具效率的選項。它是一種開源的 SQL 資料庫引擎，以其輕量級、自包含(self contained)和無需配置的特性而聞名。

### 1. SQLite 的獨特架構

SQLite 最大的不同在於其無伺服器（Serverless）的嵌入式架構：
- **嵌入式與無伺服器：** 資料庫引擎直接在**應用程式相同的程序執行緒和記憶體位址空間**中運行，無需獨立的伺服器進程。
- **自包含與輕量：** 函式庫小巧（通常小於 1MB，佔用空間不到 600KiB），完全自包含，沒有外部依賴關係。
- **單一檔案儲存：** 完整的資料庫儲存在**單一的跨平台磁碟檔案**中。任何存取該資料庫的程序都可以直接讀寫此檔案。
- **易用性：** 無需任何設定或配置即可直接使用。

### 2. SQLite 的主要應用場景

由於其輕量和易於部署的特性，SQLite 在多個領域成為首選資料庫引擎：
- **本地與客戶端儲存：**
    - 行動應用程式（Android、iOS）。
    - 桌面軟體。
    - Web 瀏覽器等應用程式軟體的本地儲存。
- **嵌入式設備：**
    - 物聯網 (IoT) 設備。
    - MP3 播放器、機頂盒等電子小工具
- **簡化檔案操作：** 當應用程式需要讀寫檔案到磁碟時，SQLite 提供 SQL 功能而不會增加複雜性。
- **開發與測試：** 具有記憶體模式 (In-memory Mode)，可快速運行測試，避免實際資料庫操作的開銷。
- **資料庫界的「隨身碟」：** 作為一個單一、輕量級的封裝，它不需要強大伺服器管理，可以輕鬆地與應用程式一起移動和安裝，是開發人員累積經驗的絕佳工具。

### 3.SQLite安裝

安裝 SQLite 資料庫引擎可前往 [SQLite 官方下載頁面](https://www.sqlite.org/download.html)下載相關作業系統的安裝檔案。
1. Windows作業系統
	向下捲動到 **"Precompiled Binaries for Windows"**，下載`sqlite-dll-win64-x64-*.zip`及`sqlite-tools-win32-x86-*.zip`兩個檔案的 ZIP 壓縮檔。將這兩個 ZIP 檔案解壓縮到電腦上的單一個資料夾中 (例如：`C:\sqlite3)`。確保 `sqlite3.exe` 和相關的 DLL 檔案都在此資料夾內。
	![[Pasted image 20251113224450.png|300]]
	
	此外，需要設定 PATH 環境變數，在 Windows 開啟「編輯系統環境變數」，在「系統變數」部分編輯 **Path** 變數，新增放置 `sqlite3.exe` 的資料夾路徑 (例如：`C:\sqlite3`)。設定完成，可以開啟**新的**命令提示字元 (`cmd`) 或 PowerShell 視窗，輸入`sqlite3`命令，若能成功進入 sqlite 命令列，表示安裝成功。
	![[Pasted image 20251113223904.png|600]]
	進入sqlite3時，若沒有指定資料庫名稱(如 test.db)則sqlite3將以暫存記憶體的資料庫為主。
	
2. mac作業系統
	在 macOS 上，SQLite 通常是預先安裝好的，無需額外安裝。只要開啟終端機 (Terminal)，輸入指令`sqlite3`，如果系統已經安裝，將直接進入 SQLite shell。
