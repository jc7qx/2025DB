# 第一節 SQL 的定義與核心用途
## 1.1 SQL是甚麼?
**SQL** 代表**Structured Query Language（結構化查詢語言）**。它是目前資料庫管理系統（DBMS）的**標準語言**。用來**存取和操作**儲存在資料庫中的資料，SQL 將儲存的大量資料**翻譯成可理解的資訊**。我們透過使用 SQL 向資料庫**提出問題**，以便理解資料庫的意義。SQL不僅能定義資料（建構資料庫），操作資料（日常查詢與分析），還能控制誰能接觸這些資料（權限管理），將龐大的原始數據轉化為決策者需要的洞見。
## 1.2 歷史沿革與國際標準
SQL 的起源可追溯到 **1970年代**。當時，**IBM SYSTEM R (DB2)** 根據關聯模式、關聯代數和關聯邏輯計算法，提出了 **SEQUEL 語言**。該語言後來被更名為 SQL。SQL 已成為資料庫管理系統的標準語言。**ANSI 和 ISO** 共同制訂了資料庫電腦語言的標準，他們以 SEQUEL 為藍本，將其命名為 SQL。儘管 SQL 已經標準化，但各家 DBMS 之間的 SQL 語法仍然存在細微差異。

隨著時間推移不斷發展，SQL的版本進程如下
* **SQL/86**
* **SQL/89**：定義了完整的限制語法。
*  **SQL/92**：劃分了四個級別，包括 entry level（入門級）、transitional level（過渡級）、intermediate level（中級）和 full level（完整級）。
*  **SQL/99**：增加了**物件導向**、**Trigger（觸發器）**，以及**遞迴查詢句**的功能。
* **SQL2003**：納入了對 **XML** 的支援。
*  **SQL2008**
## 1.3 學習 SQL 的價值
SQL 是最熱門的資料科學應用技術技能之一，建立與應用資料庫的核心技術，在各行各業中非常實用。如果不了解 SQL，你將無法成為資料科學家，甚至無法有效率地使用資料工作。如果想在現代世界中掌控資料，SQL 是最基本的技能之一。
# 第二節 SQL 資料模式與結構

SQL 的資料模式基於關聯模式。資料庫的基本概念包含資料表（Tables）和欄位（Columns）。
## 2.1 關聯模式與 SQL 術語的對應

| 關聯模式概念        | SQL 資料表術語               | 支援來源 |
| ------------- | ----------------------- | ---- |
| 關聯（Relation）  | **資料表（Table）**          |      |
| 序列值（Tuple）    | **記錄（Record）或列（Row）**   |      |
| 屬性（Attribute） | **欄位（Field）或行（Column）** |      |
## 2.2 SQL 資料表的特性
SQL 資料表與嚴格的關聯模式相比，具有以下特性：
*  **次序性：** SQL 資料表中的記錄是**有次序的**。
*  **允許重複記錄：** SQL 的資料表中**可以有兩筆一模一樣的記錄**。
*  **主鍵非強制性：** SQL 的資料表**可以不定義主鍵**。
## 第三節 指令分類與基礎語法
SQL 透過少數幾個指令，就能靈活且快速地分析任何資料庫中的資料。SQL 提供**三種**主要的指令類型，用於資料庫的不同操作層面：

1. **資料定義語言 (Data Definition Language, DDL)**
	*  用於定義**資料庫綱要（schema）**，建立及修改資料的結構。範例指令：`CREATE`、`ALTER`、`DROP`。
2. **資料處理語言 (Data Manipulation Language, DML)**
    *  用於在資料庫中執行**資料的操作**，快速查找、更新或刪除資訊。範例指令： `SELECT`、`INSERT`、`UPDATE`、`DELETE`。
3. **資料控制語言 (Data Control Language, DCL)**
	* 用於**控制資料庫的權限**。

基礎指令如下：

| 功能類型     | 關鍵指令                            | 說明                            | 支援來源 |
| -------- | ------------------------------- | ----------------------------- | ---- |
| **資料檢索** | `SELECT`, `FROM`, `WHERE`       | 檢索資料。`WHERE` 用於條件查詢。          |      |
| **資料操作** | `INSERT`, `UPDATE`, `DELETE`    | 插入、更新和刪除資料。                   |      |
| **結構操作** | `CREATE`, `ALTER`, `DROP`       | 建立、修改或移除資料表。                  |      |
| **篩選**   | `AND`/`OR`/`IN`, `LIKE`         | 用於進階條件過濾。                     |      |
| **排序**   | `ORDER BY`                      | 依據特定條件（如價格）排序結果。              |      |
| **彙總**   | `COUNT/SUM`, `AVG/MIN/MAX`      | 計算總和、平均值、最大值或最小值。             |      |
| **分組**   | `GROUP BY`/`HAVING`             | 根據特定標準對記錄進行分組。                |      |
| **限制輸出** | `LIMIT`                         | 限制查詢結果的數量。                    |      |
| **跨表連接** | `INNER JOIN`, `LEFT/RIGHT JOIN` | 結合來自多個資料表的資料。                 |      |
| **複雜查詢** | `Subquery`, `Recursive CTE`     | 涉及在一個查詢中嵌入另一個查詢（子查詢），或處理遞迴結構。 |      |
SQL 指令的最後**必須加上「;」（分號）**。
